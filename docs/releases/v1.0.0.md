## Reproduce

```sh
swift test --scratch-path .build/release-v1
xcodebuild test -scheme SheepFence -configuration Release \
  -destination 'platform=iOS Simulator,id=YOUR_SIMULATOR_ID' \
  -derivedDataPath .build/release-v1-ios \
  CODE_SIGNING_ALLOWED=NO ENABLE_TESTABILITY=YES
node --test scripts/tests/editor-*.test.mjs
.build/docs-venv/bin/python scripts/build_docs.py
```

Xcode 27.2 (27B52) was used for this run. `ENABLE_TESTABILITY=YES` is required
for the tests' `@testable` imports when testing Release configuration; the first
attempt without that setting failed before test execution. The corrected run
passed. The App Intents metadata processor emitted its expected skipped-extraction
warning because this SDK has no AppIntents framework dependency.
