# Fence Studio

[開啟 Fence Studio](editor.html)，在 OpenStreetMap 底圖上建立圍欄，匯出可供 `installSnapshot(from:)` 或 `installSnapshot(data:)` 使用的 SheepFence GeoJSON。

## 按兩下快速新增地點

放大地圖後，**按兩下建築物或地點**，即可新增包含點選位置的最小可用實體邊界，並保留 OSM 名稱與穩定識別碼。觸控與鍵盤使用者也可選擇「新增中心點地點」。例如在座標欄輸入 **38.8977, -77.0365**，再按兩下白宮建築範圍。新增的是建築邊界，與較大的總統公園不同；若要找園區，請點選周圍園地。

重複新增會選取既有圍欄；「復原」可移除剛新增的地點。手動繪製時不能快速新增。取消查詢、開始新資料集或編輯資料，都會防止過期回應新增圍欄。

快速新增使用實際包含點選位置的多邊形，不會以地址、外接矩形或任意半徑代替。室內空間與行政區界不適用。只有點位、幾何資料不完整、面積超過 25 km² 或超出編輯器限制的地點，請手動繪製。查詢失敗不會變更既有資料。

## 繪製與編輯

1. 移動地圖、輸入「緯度、經度」，或選擇「我的位置」並允許瀏覽器取得位置。
2. 選擇「繪製圍欄」，點選至少三個頂點，再選擇「完成邊界」。編輯器會自動閉合。
3. 設定穩定的要素 ID、名稱、啟用狀態與優先順序，並套用屬性。
4. 設定資料集 ID 與修訂版號，套用後下載 GeoJSON，或預覽並複製 JSON。

GeoJSON 的座標順序是 **經度、緯度**。未編輯時重複下載會得到相同位元組。匯出空資料集需要確認，因為安裝較新版的空快照會移除該資料集既有區域。

拖曳頂點可移動邊界；點選小型 **+** 控制點可插入頂點。選取頂點後可輸入精確座標或移除。窄螢幕的屬性面板位於地圖下方。「孔洞」必須嚴格位於外環內，且不能與其他孔洞重疊、相接或巢狀包含。「多邊形部分」會新增不相連的區塊，轉為 MultiPolygon。移除外環也會移除該部分的孔洞。

「復原」與「重做」涵蓋本次工作階段最多 30 次已完成的變更。繪製途中請使用「復原頂點」或「取消」；Escape 也可取消。未完成的邊界與尚未套用的表單不會匯出，請先完成或取消。

## 匯入與修訂版號

可匯入 SheepFence 快照、一般多邊形 FeatureCollection 或單一 Feature。一般 GeoJSON 使用目前的資料集資訊；缺少 ID 時會自動指派，安全整數 ID 會轉為字串。保留 Polygon、MultiPolygon 與孔洞。無效要素或不支援的幾何會拒絕整份匯入，並保留目前資料。匯入經確認後會取代目前資料集，不會合併。

SheepFence 快照的修訂版號與產生時間會保留。**修改已發布資料集後，安裝前務必增加修訂版號。**「+ 修訂版號」也會更新時間戳記。同版號但不同位元組（即使只是格式變更）可能造成 SDK 衝突。

## 驗證與限制

編輯器檢查中繼資料、座標範圍、閉合與退化環、自相交、孔洞及重複 ID。無效移動會保留上次有效形狀。跨越國際換日線的邊必須先拆成不同多邊形；不同要素可以重疊。

限制為 100 個要素、每環 1,000 個頂點、總計 10,000 個頂點，以及 5 MB 匯入／匯出。這些是編輯器限制，不代表 SDK 的全部限制。底圖使用 Web Mercator，座標導覽限制在緯度 ±85°。SDK 匯入器仍是正式驗證依據，也應實地確認邊界。

## 隱私權與地圖圖磚 {#privacy-and-map-tiles}

編輯與匯出在瀏覽器本機處理。快速新增會將點選位置的經緯度傳送至邊界查詢服務，既有圍欄幾何不會上傳。有效變更會儘可能儲存在本機儲存空間；未完成的繪製點不會自動儲存。沒有帳號、圍欄上傳端點、分析追蹤或位置歷程上傳。清除瀏覽器資料或換瀏覽器前請下載備份。私密瀏覽或儲存限制可能阻止儲存，請勿在共用瀏覽器設定檔保存敏感資料。

OpenStreetMap 會收到所瀏覽區域的圖磚請求與一般瀏覽器／網路中繼資料。畫面保留來源標示，使用正常快取，不預先下載離線地圖。「我的位置」只在您主動選取時執行，不會將位置加入匯出資料。圖磚失敗時，載入後的編輯器仍可編輯座標及匯入／匯出，但不提供離線底圖或可用性保證。

快速新增目前使用 [VK Maps 公開 Overpass 服務](https://maps.mail.ru/osm/tools/overpass/)。僅於主動新增時請求；同時最多一個請求，間隔至少兩秒，重複座標快取五分鐘，並有逾時及 5 MB 回應限制。沒有自動重試或背景掃描。匯出保留 OSM 識別碼、來源標示與 ODbL 授權參照；散布衍生資料前請閱讀 [OpenStreetMap 授權](https://www.openstreetmap.org/copyright)。高流量部署應選用容量與條款合適的圖磚及查詢服務。

## 開發維護

程式位於 `docs/site/editor.html` 與 `docs/site/assets/editor`。Leaflet 1.9.4 隨附官方發行版與授權，不需執行時 CDN。使用 `node --test scripts/tests/editor-*.test.mjs` 執行回歸測試。查詢端點與限制在 `places-config.json`。建置方式見[參與開發](contributing.md)；發布前應實際測試繪製、編輯、匯入、復原及匯出。
