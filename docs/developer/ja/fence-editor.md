# Fence Studio

[Fence Studio を開く](editor.html)と、OpenStreetMap の地図上でフェンスを作成し、`installSnapshot(from:)` または `installSnapshot(data:)` に渡せる SheepFence GeoJSON を出力できます。

## ダブルクリックで場所を追加

地図を拡大して**建物や場所をダブルクリック**すると、クリック位置を含む最小の利用可能な実体の境界を追加します。OSM の名前と安定した ID を保持します。タッチ操作やキーボードでは「地図の中心の場所を追加」も使えます。例えば **38.8977, -77.0365** に移動してホワイトハウスの建物をダブルクリックします。追加される建物の境界は、より広いプレジデンツ・パークの境界とは異なります。敷地を探す場合は周囲の庭を選択してください。

既に追加した場所は既存のフェンスを選択します。「元に戻す」で新しい追加を取り消せます。手動描画中はクイック追加できません。検索のキャンセル、新規データセット、データの編集により古い応答からの追加を防ぎます。

実際にクリック位置を含むポリゴンを使用し、住所、外接矩形、任意の半径で代用しません。屋内の部屋や行政区域は対象外です。点だけの場所、不完全な形状、25 km² を超える場所、編集上限を超える場所は手動で描画してください。検索に失敗しても既存データは変わりません。

## 描画と編集

1. 地図を移動するか「緯度、経度」を入力します。「現在地」ではブラウザーの位置情報の許可が必要です。
2. 「フェンスを描画」で 3 点以上を指定し、「境界を完成」を選びます。リングは自動的に閉じます。
3. 安定したフィーチャー ID、名前、有効状態、優先度を設定して適用します。
4. データセット ID とリビジョンを適用し、GeoJSON をダウンロードするか JSON をプレビューしてコピーします。

GeoJSON の座標順は **経度、緯度**です。編集しなければ同じバイト列を出力します。空のデータセットは確認後に出力できます。より新しい空のスナップショットをインストールすると、そのデータセットの既存領域を削除します。

頂点をドラッグして移動し、小さな **+** ハンドルで頂点を挿入します。頂点を選択すると正確な座標の入力や削除ができます。狭い画面ではプロパティパネルは地図の下に表示されます。「穴」は外周の内側に厳密に収まり、他の穴との重なり、接触、包含は禁止です。「ポリゴン部分」は離れた部分を追加して MultiPolygon に変換します。外周を削除すると、その部分の穴も削除します。

「元に戻す」「やり直す」はセッション内の完了した変更を最大 30 件保持します。描画中は「頂点を戻す」か「キャンセル」を使います。Escape でも取り消せます。未完成の境界や未適用のフォームは出力されないため、先に完了または取り消してください。

## インポートとリビジョン

SheepFence スナップショット、通常のポリゴン FeatureCollection、単一 Feature を読み込めます。通常の GeoJSON は現在のデータセット情報を使用します。欠けた ID は生成し、安全な整数 ID は文字列に変換します。Polygon、MultiPolygon、穴は保持します。無効なフィーチャーや未対応の形状があると全体を拒否し、現在のデータを保持します。インポートは確認後に現在のデータセットを置き換え、結合はしません。

SheepFence スナップショットのリビジョンと生成日時は保持します。**公開済みデータを編集した場合、インストール前にリビジョンを増やしてください。**「+ リビジョン」は日時も更新します。同じリビジョンで異なるバイト列を配信すると、整形だけの変更でも SDK の競合が発生する場合があります。

## 検証と制限

メタデータ、座標範囲、閉じたリング、退化、自己交差、穴、重複 ID を検証します。無効な移動は拒否し、直前の有効な形状を保持します。日付変更線をまたぐ辺は別々のポリゴンに分割してください。異なるフィーチャー同士は重なっても構いません。

上限は 100 フィーチャー、リングあたり 1,000 頂点、合計 10,000 頂点、入出力 5 MB です。これらは編集上限であり、SDK 全体の上限を表すものではありません。Web Mercator のため座標による移動は緯度 ±85° までです。正式な検証は Swift インポーターで行い、現地の境界も確認してください。

## 複数のフェンスを結合

2 つ以上のフェンスの横にチェックを入れ、「名前・有効状態・優先度の引き継ぎ元」を選び、「チェックしたフェンスを結合」で確認します。選択した形状は金色で表示します。対象を新しい `union-N` フィーチャーに置き換え、他のフェンスは変更しません。重なりと共有する辺を結合し、穴は別の選択領域で埋まらない限り保持します。離れた領域は MultiPolygon の別々の部分になります。外接矩形や凸包ではなく、形状の和集合です。

名前、有効状態、優先度は指定したフェンスから引き継ぎます。元の ID とプロパティは `properties.unionSources` に保存し、OSM の出典とライセンスも保持します。結果を元の OSM オブジェクトとして扱うことはありません。データセットのリビジョンは変わらないため、**編集内容の公開前にリビジョンを増やしてください**。

計算はローカルのワーカーで行い、上限は 15 秒です。「結合をキャンセル」または Escape で停止できます。データを編集した場合も処理を中止します。無効な結果や上限超過の場合、元のフェンスは変更しません。「元に戻す」で元のフィーチャーをすべて復元し、「やり直す」で再適用できます。完了した結果は草稿と GeoJSON 出力に含まれます。

## フェンスを道路まで拡張

フェンスを選択し、「最大拡張距離（メートル）」を設定して「道路への拡張をプレビュー」を選びます。周囲の道路の**中心線**から囲まれた街区を求め、提案する境界をオレンジで表示します。「道路への拡張を適用」で保存し、「道路への拡張をキャンセル」または Escape で破棄します。プレビューだけでは草稿や GeoJSON 出力を変更しません。

フェンスが内部の道路をまたぐ場合、重なる隣接街区を結合します。離れたポリゴン部分も扱い、既存の穴は除外したままです。フィーチャー ID、名前、有効状態、優先度、データセットのリビジョンは維持します。「元に戻す」で元の境界を復元できます。公開前にリビジョンを増やしてください。道路 ID、OSM の出典、ライセンスを `properties.roadAlignment` とプロパティに記録します。元の OSM オブジェクトの形状を変える場合、その出典は `originalSource` に移します。

既定の最大拡張距離は 150 メートルで、25～1,000 メートルに設定できます。保守的な局所距離の範囲で検査し、道路幅は推定しません。中心線への整合であり、縁石や法的な土地境界ではありません。幅と高さが各 2 km 以内、緯度 ±80° 以内、日付変更線付近以外のフェンスに対応し、この操作では座標位置を最大 1,200 個まで扱います。地上の車道を使用し、歩道、自転車道、駐車場通路、私道の出入口、橋、トンネル、非ゼロのレイヤーは除外します。行き止まりは街区を囲みません。不完全な道路網、未接続の交点、距離超過、無効な結果では元のフェンスを変更しません。上限を調整するか手動で編集してください。

検索では、選択したフェンスの周囲を広げた検索矩形だけを設定済みの Overpass サービスへ送ります。リング全体、名前、他のフェンスは送りません。明示的な操作でのみ検索し、キャンセル可能です。同時に 1 件、最低 2 秒間隔、セッション内のキャッシュは 5 分、応答は 5 MB とタイムアウトで制限します。ローカルのワーカー処理は 15 秒、返却道路は 600 本、線分は 3,000 本、閉じた面は 200 個までです。データの編集、フェンスの切り替え、距離変更で処理とプレビューを破棄します。公開道路データとサービスの可用性は一定ではないため、適用前に地図を確認してください。

## プライバシーと地図タイル {#privacy-and-map-tiles}

編集と出力はブラウザー内で処理します。クイック追加はクリックした経緯度を境界検索サービスに送りますが、既存フェンスの形状はアップロードしません。有効な変更は可能な場合にローカルストレージへ保存します。未完成の描画点は保存しません。アカウント、フェンスのアップロード、分析、位置履歴のアップロードはありません。ブラウザーのデータ消去や変更の前にバックアップをダウンロードしてください。プライベートブラウジングや容量制限で保存できない場合があります。共有プロファイルに機密データを保存しないでください。

OpenStreetMap は表示範囲のタイル要求と通常のブラウザー・ネットワーク情報を受け取ります。出典を表示し、通常のキャッシュを使い、オフライン地図の先読みはしません。「現在地」は選択時のみ実行し、出力データに位置を追加しません。タイルを取得できなくても、エディターの読み込み後は座標編集と入出力を続けられます。オフライン地図や稼働率の保証はありません。

現在は [VK Maps の公開 Overpass サービス](https://maps.mail.ru/osm/tools/overpass/)を使用します。明示的な追加時のみ要求し、同時に 1 件、最低 2 秒間隔、同じ座標は 5 分間キャッシュします。タイムアウトと 5 MB の応答上限があり、自動再試行やバックグラウンド走査はしません。出力には OSM ID、出典、ODbL ライセンス参照を保持します。派生データの配布前に [OpenStreetMap のライセンス](https://www.openstreetmap.org/copyright)を確認してください。高負荷の運用では用途と容量に合う地図・検索サービスを選択してください。

## 開発と保守

ソースは `docs/site/editor.html` と `docs/site/assets/editor` にあります。Leaflet 1.9.4 の公式配布物とライセンスを同梱し、実行時の CDN は不要です。`node --test scripts/tests/editor-*.test.mjs` で回帰テストを実行します。検索先と上限は `places-config.json` にあります。[開発への参加](contributing.md)に従ってビルドし、公開前に描画、編集、インポート、取り消し、出力をブラウザーで確認してください。
