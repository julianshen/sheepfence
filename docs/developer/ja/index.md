# 位置を知る。測位の不確かさも把握する。

SheepFence は、フォアグラウンドで動作するポリゴン型ジオフェンシング用 Swift SDK です。独自の GeoJSON 領域を読み込み、オフラインで位置を判定し、確認済みの進入・退出イベントを受け取れます。GPS が使えない状態を「領域外」と誤判定しません。

**Swift 6 · iOS 16+ · Swift Package Manager · SDK の外部依存なし**

## フェンスデータを作成する

[Fence Studio](editor.html) では、OpenStreetMap 上で領域を描画・編集できます。地図上の場所をダブルクリックして境界を取得し、SheepFence 用 GeoJSON スナップショットとして出力することもできます。アカウントや API キーは不要です。

## 操作を選ぶ

| 目的 | API |
|---|---|
| GPS 測位がどの領域内にあるか調べる | `evaluate(location:)` |
| 指定領域に座標が含まれるか調べる | `query(coordinate:in:)` |
| 領域までの距離を取得する | `distance(from:to:)` |
| アプリの位置情報源で境界通過を追跡する | `.hostProvided` と `submit(location:)` |
| SDK の位置情報源を使う | `startMonitoring(mode: .sdkManaged)` |
| 現在の状態を取得する | `state()` |
| 観測や境界通過イベントを購読する | `events()` |

## 現在の観測と履歴を区別する

重なり合う複数の領域が同時に一致することがあります。観測結果は、確認済み、境界付近で不確定、位置情報利用不可を区別し、使用したデータセットのリビジョンも示します。測位が途絶えた場合、最後の確認結果は履歴として残り、架空の退出イベントは発生しません。

スナップショットはトランザクションで更新します。更新に失敗しても既存データは利用でき、形状の置換は移動ではなく基準の再設定として扱います。

## 現在の状態

SDK は `main` ブランチで提供しており、バージョンタグは未公開です。記録済みのチェックポイントでは 25 スイート・139 テスト、シミュレータテスト、iPhone のスモークテストと 100 領域の合成ベンチマークに合格しています。Codex、OpenCode、pi による相互レビューも完了しています。これらは特定時点の記録であり、性能保証ではありません。

対応する統合形態はフォアグラウンドです。実経路での精度、消費電力の調整、権限変更時の実機検証は別途必要です。バージョン付き配布の前にライセンスも選定する必要があります。
